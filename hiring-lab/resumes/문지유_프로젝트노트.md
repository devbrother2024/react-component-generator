# 문지유 · 주문·재고 프로젝트 보충 노트

강의 실습용 가상 지원 서류입니다. 기준 시점은 2026년 10월입니다.

## 첨부 자료와 담당 범위

이력서와 PDF 포트폴리오에 소개한 셀러브릭 작업을 보충합니다. 세 문서는 같은 재직 기간인 2024년 1월부터 2026년 8월까지의 작업이며, 프로젝트별 기간을 따로 더해 경력을 계산하지 않습니다.

## 주문 수집의 중복 데이터 처리

웹훅 수신과 적응형 폴링이 같은 주문을 가져올 수 있어 두 경로를 BullMQ 큐로 합쳤습니다. 제가 담당한 수집 모듈에서는 PostgreSQL에 몰 ID와 주문 번호의 유니크 키를 두고 upsert하도록 구현했습니다. 처리에 실패한 작업은 별도 큐로 분리해 알림을 보냈습니다.

웹훅 지원 몰 7곳과 나머지 5곳의 처리 경로를 하나로 통합했습니다. 웹훅이 없는 몰은 여전히 반영이 늦고, 쇼핑몰 API 스펙 변경 감지는 다음 과제로 남았습니다.

## 테스트 결과를 읽을 때의 범위

PDF 포트폴리오의 SSE 동시 연결 3,000개·CPU 45%는 k6로 측정한 스테이징 환경의 결과입니다. 당시 운영 최대 동시 접속은 약 1,100개여서 같은 숫자로 해석하지 않았습니다.

주문·재고 통합 테스트는 Claude Code가 만든 테스트 초안에 mock이 과하게 들어가는 문제를 보고 보강했습니다. 커버리지 41% → 78%와 핫픽스 월 6건 → 2건은 이력서에 적은 같은 8주 개선 작업의 결과입니다.

회사 서비스의 실제 코드나 운영 데이터는 포함하지 않았습니다. 재직 기간은 이력서에, 대안 비교와 측정 조건은 PDF 포트폴리오에 적었습니다.
