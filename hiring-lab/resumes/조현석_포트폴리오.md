# 조현석 · 유지보수와 기능 개발 작업 소개

강의 실습용 가상 지원 서류입니다. 기준 시점은 2026년 10월입니다.

## 배차 API 유지보수

타임딜리버리에서 배차 API 유지보수와 기능 개발을 맡았습니다. 점심 피크의 배차 지연 대응에 참여했고, 슬로 쿼리와 커넥션 풀 문제를 확인해 인덱스 추가와 설정 조정을 적용했습니다. 이력서의 p95 4.2초 → 0.9초는 이 대응에서 기록한 값입니다. 비교 기간과 요청 수를 정리한 원본 표는 별도로 첨부하지 않았습니다.

API 명세와 신규 테이블 구조는 리드와 DB 담당자가 확정했습니다. 저는 확정된 명세를 구현하고 기존 쿼리를 수정하는 역할을 맡았습니다. API·데이터 모델을 처음부터 독자적으로 설계한 프로젝트라고 소개하지 않습니다.

## 공공 SI 유지보수

새길정보기술에서 민원 포털 화면과 API 유지보수, SQL 튜닝, 고객 요청 대응을 했습니다. 통계 시스템 고도화에서는 조회 화면과 일 단위 집계 배치를 만들고 단위 테스트 결과서를 작성했습니다. 업무 범위와 기간은 이력서의 프로젝트 표에 정리했습니다.

## 협업 자료

배포 스크립트와 배포 가이드를 정리했습니다. 기능 수정 뒤 확인할 화면과 배치 작업을 가이드에 기록했습니다. 회사 산출물 원문은 첨부하지 않았습니다.
