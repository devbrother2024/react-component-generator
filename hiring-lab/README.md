# 이력서 1차 검토 실습 (리더 과정)

`resumes/`의 이력서와 포트폴리오는 **강의 실습용 가상 서류**다. 등장하는 사람, 회사, 학교, 서비스, 연락처는 모두 지어낸 것이며 실존 인물·기관과 관계가 없다. 실제 백엔드 개발자 이력서들에서 흔히 보이는 구성과 서술 패턴을 참고해 합성했고, 특정인의 이력은 담지 않았다.

- 서류: PDF 6개 (지원자 5명, 한 명은 이력서와 포트폴리오)
- 스킬: `.claude/skills/resume-screening/` (평가 기준은 `references/criteria.md`)
- 리뷰어 서브에이전트: `.claude/agents/resume-reviewer.md`
- 실행: Claude Code에서 `/resume-screening hiring-lab/resumes`
- 결과: `hiring-lab/results/` (실행마다 새로 만들어지며 git에는 올리지 않는다)
